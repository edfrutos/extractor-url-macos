Extractor URL

Convierte páginas web en Markdown, HTML o texto limpio, en tu Mac y sin servicios externos.

Qué hace

  • Extrae el contenido principal de una página y descarta menús, anuncios y pies.
  • Lo convierte a Markdown, HTML o texto plano.
  • Renderiza las páginas que necesitan JavaScript.
  • Acota la extracción con un selector CSS.
  • Abre páginas HTML guardadas en tu Mac.
  • Exporta a Markdown, HTML o PDF, o copia el resultado.
  • Guarda un historial local para repetir extracciones.

Dónde conseguirla

  • Mac App Store: próximamente.
  • Descarga directa: en las versiones de GitHub, firmada y notarizada por Apple.

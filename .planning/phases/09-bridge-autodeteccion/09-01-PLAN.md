  1. Añadir el enum PathSource como tipo privado dentro de la clase PythonBridge (no como tipo de nivel de módulo):
     - Casos: `bundle` y `userDefaults`

  2. Añadir el método `internal func resolvedPaths() -> (python: String, script: String, source: PathSource)?`:
     - Intento 1 (UserDefaults): leer `UserDefaults.standard.string(forKey: "pythonPath")` y `UserDefaults.standard.string(forKey: "scriptPath")` — NO usar `self.pythonPath` ni `self.scriptPath` para evitar dependencia de @MainActor en contexto async (Pitfall 3 del RESEARCH).

  3. Reemplazar en `run()` el bloque de líneas 35-65 (los dos guards + la configuración de entorno con .venv) por:
     - `guard let paths = resolvedPaths() else { throw ExtractionError.pythonNotFound(path: "(bundle no compilado)") }`
     - Asignar: `let pythonExec = paths.python` y `let scriptFile = paths.script`
     - Usar `pythonExec` en `process.executableURL` y `scriptFile` como primer argumento.
     - Construir `var env = ProcessInfo.processInfo.environment` y luego bifurcar con `switch paths.source`:
       - `.bundle`: si `Self.bundledVendoredLibPath()` no es nil, añadir a PYTHONPATH con prefijo (preservar PYTHONPATH existente si no vacío). No establecer VIRTUAL_ENV. `process.currentDirectoryURL` = directorio del scriptFile.
       - `.userDefaults`: comportamiento v2.0 — calcular `scriptDir`, `venvBin = scriptDir + "/.venv/bin"`, establecer `env["VIRTUAL_ENV"]` y `env["PATH"]`. `process.currentDirectoryURL` = URL del scriptDir.
     - Asignar `process.environment = env` tras el switch.
     - El resto de run() (Pipes, IOCollector, readabilityHandler, decodificación JSON) permanece sin cambios.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UserDefaults → Process.executableURL | Las rutas leídas de UserDefaults se pasan como ejecutable al subprocess sin interpolación de shell |
| Bundle.main.resourcePath → Process arguments | Las rutas construidas desde resourcePath se pasan como argumento posicional |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | UserDefaults "pythonPath" / "scriptPath" | mitigate | `FileManager.default.isExecutableFile` valida que la ruta existe y tiene permisos de ejecución antes de usarla. La ruta se pasa como `URL(fileURLWithPath:)` a `Process.executableURL` — no se interpola en strings de shell, por lo que path traversal con espacios o metacaracteres no se ejecuta como código. |
| T-09-02 | Elevation of Privilege | Subprocess lanzado con binary arbitrario desde UserDefaults | accept | App Sandbox OFF por decisión de arquitectura v3.0. Uso personal sin acceso de terceros al Mac. El binario debe ser ejecutable por el usuario actual — no hay escalada de privilegios posible con esta restricción. |
| T-09-SC | Tampering | npm/pip/cargo installs | accept | Esta fase no instala paquetes externos. No aplica slopcheck. |
</threat_model>

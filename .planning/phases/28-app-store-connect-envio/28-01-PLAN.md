# 28-01 — Páginas públicas, ficha y subida automatizada

## Objetivo

Dejar listo todo lo que no exige el Mac ni App Store Connect:

- las URL de privacidad y soporte publicadas;
- los textos de la ficha;
- el script que sube el build.

Ver `28-RESEARCH.md`.

## Tareas

### T1 — GitHub Pages en `docs/` (STORE-03)

- **`docs/index.html`**: qué es Extractor URL, enlaces a privacidad,
  soporte, al repositorio y a la descarga directa (Releases).
- **`docs/privacidad.html`**: la política de `28-RESEARCH.md`, con fecha de
  vigencia y contacto por issues.
- **`docs/soporte.html`**:
  - requisitos (macOS 13.5+);
  - preguntas frecuentes: páginas con JavaScript, 403, «Abrir HTML…»,
    volver a elegir un archivo del historial;
  - cómo abrir un issue.
- **`docs/estilo.css`** compartido:
  - claro y oscuro (`prefers-color-scheme`);
  - fuente del sistema;
  - legible en móvil.
- **`docs/.nojekyll`**.
- Todo en español de España, `lang="es"`, sin JavaScript ni recursos
  externos.
- **Publicar:** push a `main` y `gh api -X POST
  repos/edfrutos/extractor-url-macos/pages -f 'source[branch]=main' -f
  'source[path]=/docs'`. Comprobar que las tres URL responden 200 con
  `curl`.

### T2 — Ficha (STORE-02)

**`appstore/FICHA.md`**, con cada campo, su límite y el recuento de
caracteres:

- nombre y subtítulo;
- texto promocional, descripción y palabras clave;
- URL de soporte, de marketing y de privacidad;
- categoría (Productividad; secundaria: Herramientas para desarrolladores);
- precio: gratis;
- respuestas del cuestionario de edades;
- etiqueta de privacidad;
- cumplimiento de exportación: no usa cifrado propio;
- las 3–5 capturas propuestas;
- notas para App Review.

### T3 — Copyright

`NSHumanReadableCopyright` = «© 2026 Eugenio de Frutos Sánchez» en
`Info.plist` y `AppStore-Info.plist`.

### T4 — Subida en `package-appstore.sh` (STORE-04)

- **`APPSTORE_BUILD`** opcional: se pasa a `xcodebuild archive` como
  `CURRENT_PROJECT_VERSION=…`. Si falta y el build del `.app` es 13 o
  menor, avisa de que App Store Connect lo rechazará.
- **Paso 6, solo con `UPLOAD=1`**:
  - exige `ASC_KEY_ID` y `ASC_ISSUER_ID`;
  - comprueba que existe `~/.appstoreconnect/private_keys/AuthKey_${ASC_KEY_ID}.p8`;
  - `xcrun altool --validate-app --type macos -f "$PKG" --apiKey … --apiIssuer …`;
  - después, `--upload-app` con los mismos argumentos.
- Sin `UPLOAD=1`, todo sigue como hoy (mensaje de Transporter).
- Actualizar la cabecera del script.
- `bash -n` y `shellcheck` si está disponible.

### T5 — `RELEASING.md` §3.9

- Crear la clave de API (Usuarios y acceso → Integraciones → App Store
  Connect API, rol «Developer»).
- Dónde guardar el `.p8`.
- El comando completo con `APPSTORE_BUILD` y `UPLOAD=1`.
- Transporter como alternativa.
- Enlace a `appstore/FICHA.md` y a las páginas públicas.

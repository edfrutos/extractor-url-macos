# 26-02 — App: render con `WKWebView` en la variante App Store

## Objetivo

En la variante App Store, cuando la CLI dice `js_render_needed`, renderizar
la página en un `WKWebView` oculto y convertir ese HTML. Si el render falla,
quedarse con el estático y avisar. La variante Developer ID no cambia de
comportamiento: sigue con Playwright y nunca pasa `--js-external`.

## Tareas

### T1 — `ExtractionResult` y `PythonBridge`

- `ExtractionResult.jsRenderNeeded: Bool?` (`js_render_needed`). Más
  `var needsJSRender: Bool { jsRenderNeeded == true }`.
- `PythonBridge.run`: parámetro nuevo
  `source: Source = .url(String)` / `.renderedHTML(file: URL, baseURL: String)`,
  o bien parámetros opcionales `fileURL`/`baseURL`. Lo que encaje mejor con
  el código; las llamadas actuales deben compilar igual.
  - Parámetro `externalJS: Bool = false` → `--js-external`.
  - Parámetro `jsMode: String? = nil` → `--no-js` si es `"off"`.
  - `.renderedHTML` → `--file <ruta> --base-url <url>` en lugar de la URL
    posicional.

### T2 — `Models/Services/WebRenderer.swift` (WKJS-02)

`@MainActor final class WebRenderer: NSObject, WKNavigationDelegate`.

- **Configuración:**
  - `WKWebViewConfiguration` con `websiteDataStore = .nonPersistent()`.
  - `WKWebView(frame: 1280×800)`, sin añadirlo a ninguna ventana.
- **`func render(url: URL, timeout: TimeInterval) async throws -> (html: String, finalURL: URL)`.**
  - Carga con `URLRequest(url:, timeoutInterval: timeout)`.
  - `decidePolicyFor navigationResponse`: guarda `statusCode`;
    ≥ 400 → `RenderError.httpStatus(code)` al terminar.
  - `didFinish` → bucle de sondeo cada 0,5 s con
    `evaluateJavaScript("document.body ? document.body.innerText.length : 0")`.
    Para cuando hay ≥ 100 caracteres y dos lecturas seguidas iguales, o
    cuando se agota el plazo total.
  - Al parar: `evaluateJavaScript("document.documentElement.outerHTML")` y
    `webView.url` como `finalURL`.
  - `didFail` / `didFailProvisionalNavigation` → `RenderError.navigation(error)`.
  - Plazo agotado sin `didFinish` → `RenderError.timeout`.
  - Siempre `stopLoading()` y se libera el `WKWebView` al terminar.
- **Solo en `#if DEBUG`:** si `UserDefaults.standard.bool(forKey:
  "webRendererForceFailure")`, lanza `RenderError.forcedForTesting` sin
  cargar nada. Así el checkpoint prueba la degradación con
  `-webRendererForceFailure YES` en los argumentos del esquema.
- **`enum RenderError: LocalizedError`**: textos en español, por ejemplo
  «La página no terminó de cargar en el tiempo límite.».
- **Comentario de cabecera:** por qué no se usa Playwright aquí (sandbox,
  Fase 26) y por qué se sondea en lugar de esperar a `networkidle`.

### T3 — Orquestación en `ExtractionViewModel` (WKJS-02/03/04)

- **Estado nuevo:**
  - `@Published var renderWarning: String?`, que se limpia en `extract()`
    igual que `errorMessage`.
  - `private var lastRenderedHTML: (html: String, baseURL: String)?`.
- **`extract()`**, dentro de la tarea:
  1. `r1 = bridge.run(url, …, externalJS: Self.usesExternalJS)`, donde
     `usesExternalJS` es `true` solo con `#if APPSTORE`.
  2. Si `r1.needsJSRender` (solo puede pasar en App Store):
     - Hacer `await WebRenderer().render(...)` en el MainActor.
     - Escribir el HTML en `temporaryDirectory/<UUID>.html` y llamar a
       `bridge.run(.renderedHTML(file, baseURL: finalURL), …)`. Borrar el
       temporal con `defer`.
     - Guardar `lastRenderedHTML`.
     - Si el render lanza un error:
       - `r = bridge.run(url, …, externalJS: true, jsMode: "off")`.
       - `renderWarning = "No se pudo ejecutar el JavaScript de la página
         (\(error.localizedDescription)). Se muestra el contenido sin
         JavaScript, que puede estar incompleto."`.
  3. Se publica el resultado igual que hoy. `sourceURL` es la `url` del
     resultado, que con `--base-url` ya es la de origen.
- **`markdownForExport()`:** si hay `lastRenderedHTML`, reconvierte ese HTML
  (temporal + `.renderedHTML`). Si no, igual que hoy.
- **`openLocalHTML()`:** sin cambios. `file://` nunca pide render.
- **Nombres:** igual que en el resto del archivo (`D-xx` no hace falta).

### T4 — Aviso en `ContentView`

- `Image(systemName: "exclamationmark.triangle")`;
- el texto en `.secondary` y `.font(.callout)`;
- el mismo estilo que el resto de avisos de la vista.

No bloquea el resultado ni la exportación.

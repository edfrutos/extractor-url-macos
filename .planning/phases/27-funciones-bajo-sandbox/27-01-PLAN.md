# 27-01 — Copiar, reabrir archivos locales y errores en App Store

## Objetivo

Cerrar los huecos que deja el sandbox (ver `27-RESEARCH.md`):

- copiar al portapapeles desde la app;
- reabrir desde el historial un HTML local tras relanzar;
- el enlace a Ajustes que no sirve en App Store.

El resto (exportar, historial, «Abrir HTML…») se verifica en el
checkpoint.

## Tareas

### T1 — «Copiar» con `NSPasteboard` (SBXFEAT-04)

- **`ExtractionViewModel.copyResult()`**:
  - Si no hay `resultContent`, no hace nada.
  - `NSPasteboard.general.clearContents()`, y luego `setString(content,
    forType: .string)`. Si `resultOutputType == "html"`, también
    `setString(content, forType: .html)`.
  - `@Published var didCopy` se pone a `true` y vuelve a `false` a los 1,5 s
    (con `Task.sleep`, en el MainActor).
- **`ContentView`**:
  - Botón «Copiar» (`doc.on.doc`) junto a los de exportar, con el mismo
    estilo.
  - Deshabilitado sin resultado o durante la extracción.
  - `.keyboardShortcut("c", modifiers: [.command, .shift])` y `.help`.
  - Con `didCopy`, la etiqueta pasa a «Copiado» (`checkmark`).
- **Test**: `copyResult()` deja el contenido en el portapapeles. Usar un
  `NSPasteboard(name:)` propio inyectable para no pisar el del usuario:
  `copyResult(to pasteboard: NSPasteboard = .general)`.

### T2 — Reabrir un HTML local sin permiso (SBXFEAT-02)

- **`ExtractionViewModel.reopen(_ entry: HistoryEntry) async`**: mueve aquí
  lo que hace hoy el cierre de `HistoryView` en `ContentView` (URL, tipo,
  selector, `extract()`).
  - Si la URL es `file://` y
    `!FileManager.default.isReadableFile(atPath:)`:
    - Abre un `NSOpenPanel` con `directoryURL` en la carpeta del archivo,
      el archivo preseleccionado si existe, `allowedContentTypes = [.html]`
      y el mensaje «Vuelve a elegir el archivo para darle permiso a la
      app».
    - Si el usuario acepta, extrae la URL elegida.
    - Si cancela, no hace nada.
  - Con permiso, o con URL http(s), se comporta exactamente igual que hoy.
- **`ContentView`**: el cierre de `HistoryView` llama a
  `Task { await vm.reopen(entry) }`.
- **Test**: `reopen` con una URL http rellena `urlString`, `outputType` y
  `selectorCSS` y lanza la extracción (`isExtracting` pasa a `true`).

### T3 — Errores en App Store (SBXFEAT-05)

- **`ContentView`**: el enlace «Abrir Ajustes…» de `isPythonPathError` va
  en `#if !APPSTORE`. En App Store, Ajustes no tiene rutas, y el mensaje de
  `SettingsView` ya pide reinstalar.
- **pytest** (`tests/test_external_render.py`): para un error de red
  (`ConnectionError` simulado) y un selector inexistente, el JSON con
  `--js-external` es igual que sin él, salvo `js_render_needed`.

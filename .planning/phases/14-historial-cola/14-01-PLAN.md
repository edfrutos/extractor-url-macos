<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URLs del usuario → `history.jsonl` | Las URLs y títulos extraídos se escriben en un archivo local sin transmitirse a ningún servicio externo — mismo nivel de confianza que la caché HTTP ya existente |
| Archivo de `--batch` → bucle de extracción | Cada línea se trata como una URL independiente vía las mismas funciones ya validadas (`extract_formatted_content`), sin interpolación en shell ni en queries — sin superficie de inyección nueva |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Information Disclosure | `history.jsonl` en texto plano | accept | Uso personal de un solo usuario en su propio Mac — mismo nivel de sensibilidad que el historial de cualquier navegador; no requiere cifrado para este caso de uso. |
| T-14-02 | Denial of Service | `--batch` con un archivo enorme de URLs | accept | Procesamiento estrictamente secuencial (una URL a la vez, mismo timeout por defecto que una extracción individual) — el usuario controla el tamaño del archivo que él mismo proporciona; no hay entrada no confiable de terceros aquí. |
| T-14-SC | Tampering | npm/pip/cargo installs | accept | Este plan no añade dependencias — solo stdlib de Python (`json`, `datetime`, `pathlib`). |
</threat_model>
